# District Planner — планировщик квартала для Workers & Resources: Soviet Republic

Неофициальный мод-оверлей: рисуете участок на карте, выбираете дома и службы — мод прямо поверх игры
показывает план квартала (дома, службы, улицу, остановки, дорожки, объёмы земляных работ).

> **Статус: v0.5, предпросмотр + выравнивание земли.** Мод показывает план и умеет выровнять землю под зданиями. Кнопка «Построить в игре»
> ещё в разработке — здания нужно ставить вручную по плану. Проверено на игре 1.1.1.13 (64 бит, DX11).

## Установка

1. Соберите `build\dinput8.dll` (см. «Сборка») или возьмите готовую из релизов.
2. Положите `dinput8.dll` рядом с `SOVIET64.exe` (корень папки игры).
3. Запустите игру как обычно. Удаление мода — удалить этот `dinput8.dll`.

Мод создаёт рядом с exe два файла: `DistrictPlanner.log` (журнал) и `DistrictPlanner.ini` (положение окон).
Сохранения игры мод не трогает.

## Как пользоваться

1. Загрузите карту или сохранение. Через несколько секунд слева появится квадратная кнопка с домиками
   (её можно перетаскивать). Кнопка или **F8** открывает/закрывает панель «Планировщик квартала».
2. Вкладка **Участок**
   - «Нарисовать на карте» — щёлкайте левой кнопкой по углам участка (любой многоугольник).
     Замкнуть контур: **Enter** или щелчок по первой точке. «Сбросить» — убрать участок.
   - «поворот застройки» — под каким углом идут ряды домов.
   - Подсветка склонов: оранжевый > 12 %, красный > 25 %.
   - «показывать выравнивание» — здания рисуются объёмом на выровненной площадке, жёлтые линии — срез/насыпь.
   - «допустимый перепад под зданием» — места круче этого планировщик пропускает.
   - Население квартала и отступ между зданиями.
3. Вкладка **Дома** — отметьте типы жилых домов (поиск по названию, «только выбранные», «Снять все»).
   Дома расставляются по очереди, пока не наберётся заданное население.
4. Вкладка **Службы** — магазин, детсад, школа и т.д.: включить, выбрать тип здания, норма «одно на N жителей».
5. Вкладка **Дороги** — тип дороги (нет / улица / проспект), автобусные остановки (добавить, убрать,
   перетаскивать мышью прямо на карте), радиус «сколько идут до остановки».
   «улица через каждые, м» добавляет параллельные улицы, чтобы дороги покрывали весь участок (0 — одна улица).
6. Внизу панели — итог: число домов и мест, длина дорог и дорожек, м³ срезать/насыпать, рабочие места в службах и примерное число работников,
   самая дальняя дорога до остановки и магазина, что не поместилось. Дома дальше радиуса от остановки
   помечаются.

6a. Вкладка **Сети** — вода, канализация, отопление, электричество: галочка показывает сеть на карте
   (цветные линии вдоль дорожек и улиц, не под домами; квадраты — узлы у улиц). Для каждой сети задаётся
   радиус обслуживания узла и норма на жителя; показываются число узлов, нагрузка и длина траншей.
   Нормы — прикидка, а не цифры из игры: подставьте свои. Сети в игре пока строятся вручную.
7. Кнопка **«Пересобрать план»** заново читает рельеф и расставляет всё по участку (например, после выравнивания).
8. Кнопка **«Выровнять землю под зданиями»** сразу ставит землю под каждым зданием плана на высоту его
   площадки. Это бесплатно и без техники (в обход игровой экономики), отменить нельзя — сохранитесь заранее.
   Клетка рельефа в игре около 10 м, поэтому между близко стоящими домами остаётся перепад.

## Как это работает

- **Загрузка.** `dinput8.dll` — прокси-библиотека: игра сама загружает её при старте, а все вызовы
  DirectInput передаются настоящей системной `dinput8.dll`. В других процессах DLL ничего не делает.
- **Доступ к движку.** Движок игры `C3DDLL64.dll` экспортирует именованные методы C++
  (`C3D_CAMERA`, `C3D_TERRAIN`, `C3D_INPUT`, `C3D_BUILDING`). Мод подменяет записи таблицы импорта (IAT)
  в `SOVIET64.exe` и так узнаёт указатели на камеру и рельеф, читает матрицы вида/проекции и высоты
  земли. Память игры не патчится, кода игры в моде нет (`src/engine.cpp`).
- **Оверлей.** После старта движка мод перехватывает `IDXGISwapChain::Present` и рисует панель
  через Dear ImGui (DX11). Ввод идёт через хук `WH_GETMESSAGE`; пока курсор над панелью,
  игра не видит кнопок мыши и колеса (`src/main.cpp`).
- **Каталог зданий.** Читаются `media_soviet/buildings_types/*.ini` (тип, вместимость, качество жилья,
  рабочие места, материал), `.bbox` (размер) и названия из `sovietRussian.btf` (`src/catalog.cpp`).
- **Планировщик.** В местной системе координат участка: улица с остановками, по обе стороны — полосы
  «ряд домов / дорожка / ряд домов», службы ближе к улице, крутые места пропускаются, для каждого
  здания считается площадка и объём земли (`src/planner.cpp`).
- **Выравнивание.** Вызывается функция движка `C3D_TERRAIN::EditRaiseLower` с открытой картой высот
  (`HeightmapTextureOpen/Close`), по одной клетке карты высот, из потока отрисовки (`src/engine.cpp`).
- **Интерфейс и отрисовка на карте** — `src/ui.cpp`.

## Сборка

Нужны Visual Studio Build Tools (x64, C++17) и Dear ImGui:

```bat
git clone https://github.com/ocornut/imgui third_party\imgui
build.bat
```

Путь к `vcvars64.bat` задан в `build.bat` — поправьте под свою версию Visual Studio.
Результат: `build\dinput8.dll`.

## Отладка

- Журнал: `DistrictPlanner.log` рядом с `SOVIET64.exe`.
- Самопроверка: создайте пустой файл `DistrictPlanner.selftest` рядом с exe (можно при запущенной игре) —
  мод сам очертит тестовый участок в центре экрана и запишет результат в журнал.

## Планы

Реальное строительство (за деньги / за ресурсы, очередь задач), выравнивание за деньги/техникой, кривые улицы,
маршруты транспорта, подбор мощности сетей по настоящим цифрам игры, оценка стоимости,
баланс рабочих мест, промышленность, парки, обход существующих дорог и зданий, фильтр по году,
здания из Мастерской.
