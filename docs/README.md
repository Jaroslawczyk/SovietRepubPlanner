# Справочник по игре (для разработки мода)

Всё, что выяснено о том, как работает Workers & Resources: Soviet Republic (сборка 1.1.1.13), собрано здесь.
Каждый факт помечен источником: **[файлы]** — прочитано из файлов игры, **[игра]** — увидено в самой игре
(скриншот, журнал вызовов), **[код]** — из дизассемблера `SOVIET64.exe` / `C3DDLL64.dll`, **[?]** — не проверено.

| Файл | Что внутри |
|---|---|
| [mechanics.md](mechanics.md) | Правила игры: коммуникации, пешая доступность, размещение зданий, дороги и дорожки. Список открытых вопросов. |
| [buildings.md](buildings.md) | Все 488 зданий: размер, занимаемая зона, рабочие, вместимость, потребление, производство, число подключений каждого вида. Генерируется. |
| [data/buildings.json](data/buildings.json) | То же полностью: координаты каждой точки подключения и каждой мёртвой зоны. Генерируется. |
| [loads.md](loads.md) | Нагрузка каждого здания на тепло и электричество и ёмкость узлов — по формулам из exe. Генерируется. |
| [internals.md](internals.md) | Внутренности exe: адреса функций, менеджеры сетей, типы линий, как мод вызывает постройку; флаг допустимости предпросмотра `mgr+0x315`, мощность проводов, поиск ЛЭП и подъездов (v0.62–v0.70). |

Обновить генерируемые файлы: `python tools/gen_docs.py` (из папки `DistrictPlanner`).

Порядок работы: новое знание об игре сначала записывается сюда (с пометкой источника), потом используется в коде.

- [industry.md](industry.md) — цепочки производства из ini игры, как считает вкладка «Промышленность», открытые вопросы (генерируется tools/gen_industry.py)

Состояние на v0.70 (2026-11-18, проверено в игре селфтестами): обычный район — улицы 43/43, дорожки 92/95, ЛЭП 14/14,
подъезды 5/5; плотный район — улицы 105/106, дорожки 174/177, ЛЭП 34/34, подъезды 16/16; неровный контур с окружной —
улицы 50/50, дорожки 12/12, подъезды 7/7.
